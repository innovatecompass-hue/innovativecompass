# Testimonial

A single client quote in `quote` (Playfair, up to 34px) on `cream`, with a role-only attribution.

```html
<section class="testimonial cream">
  <div class="container">
    <div class="inner">
      <blockquote>"…"</blockquote>
      <div class="attribution">— Founder, Professional Services</div>
    </div>
  </div>
</section>
```

- **You provide:** the quote in straight double quotes, and an attribution that starts with an em dash and gives role and sector, not a name.
- **Style:** the quote is `ink`, max 780px; the attribution is `overline` in `taupe`. That attribution pair is 2.1:1, flagged.
- **One quote per page.** No photos, no logos, no star ratings.
