# Eyebrow

The small uppercase label above every section heading, led by a 40px `gold` dash.

```html
<span class="eyebrow">The Real Cost</span>
<h2>The cost of a disorganized business isn't in the books.</h2>
```

- **You provide:** two to four words in Title Case. CSS sets them uppercase.
- **Style:** `overline` (11px, 500, 0.18em) in `label`, which is `taupe` on light grounds. Inside `.dark` the text and dash turn `gold-soft`.
- **Spacing:** `space-24` to the heading below; the dash sits `space-14` from the text.
- **Every section opens with one**, and the words name the beat: "The Method", "What Changes", "If This Resonates".
- **Contrast:** `taupe` on `cream` is 2.1:1, below WCAG AA. That's the source's pair, flagged.
